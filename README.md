# MEG WORLD HRMS — Aqua Glass UI

A responsive React + Vite HRMS demo redesigned with a soft aqua/teal glassmorphism theme inspired by the provided dashboard reference.

## Included
- Reusable React header and sidebar components
- Separate pages and CSS files retained from the supplied project
- Translucent glass panels and KPI cards with soft shadows
- Floating animated HR icon tiles and ambient background effects
- Hover lift, staggered entrance animations, and responsive mobile navigation
- Existing mock dashboard data, charts, calendar, and demo interactions retained

## Run locally
1. Install Node.js (18+ recommended).
2. Extract this ZIP and open the project folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

This is the existing frontend demo; no backend or database was added. Dashboard figures remain mock data.
